# WorldBuilder Toolkit 1.9 한국어 빠른 사용법

## 언어

`3D Viewport > N > WorldBuilder` 최상단에서 `언어 = 한국어`를 선택합니다. 내부 `assetId`, `stableId`, `GEOMETRY`, `INSTANCE`, `CH_*` 값은 Unity 호환을 위해 번역하지 않습니다.

## 선택 청크 지형 생성

1. `World Grid > Chunk Select Tool`로 청크를 선택합니다.
2. `청크 지형` 패널을 엽니다.
3. 범위를 `활성 청크`, `선택한 청크`, `사각형 범위` 중 하나로 지정합니다.
4. 기본값은 `청크당 셀 수 = 64`를 권장합니다.
5. `선택 청크 지형 생성`을 누릅니다.

지형은 authoritative `Chunk Size`와 `World Origin`을 사용하고 `CH_*` 컬렉션, `GEOMETRY`, Stable ID, Biome Target, Dirty 상태가 자동 설정됩니다. 인접 청크는 생성 시점과 순서가 달라도 같은 전역 좌표 높이를 사용합니다.

## 여러 청크 Sculpt

1. 조형할 청크를 선택합니다.
2. `지형 조형 > 조형 세션 시작`을 누릅니다.
3. Blender Sculpt Mode에서 Grab, Smooth, Clay, Inflate, Flatten 등 고정 토폴로지 브러시를 사용합니다.
4. 완료하면 `조형 적용`, 버리려면 `조형 취소`를 누릅니다.

내부 청크 경계는 임시 Proxy에서 Weld되고 외곽 경계는 Mask됩니다. Dyntopo, Voxel Remesh, 토폴로지 변경 Modifier를 사용하면 Apply가 차단됩니다. 결과는 `wb_sculpt_delta`에 저장되므로 Spline Carve 재생성 시에도 유지됩니다.

## 수직 레이어로 위아래 작업하기

세로로 긴 맵에서 층을 오가며 작업하기 위한 기능입니다. `수직 레이어` 패널에서 설정합니다.

1. `레이어 높이`와 `레이어 기준 Z`, `레이어 개수`를 정합니다. 예: 높이 16m, 기준 0, 개수 8이면 0~128m를 8층으로 나눕니다.
2. 패널의 위/아래 화살표로 활성 레이어를 이동합니다. 3D Cursor Z도 해당 층 가운데로 따라갑니다.
3. `그리드가 레이어 따라감`을 켜면 청크 그리드가 활성 레이어 바닥에 그려집니다. 위층에서도 청크 경계가 보입니다.
4. `격리 보기`를 `활성 레이어` 또는 `활성 레이어 이하`로 두면 다른 층이 뷰포트에서 숨겨집니다. `전체 표시`로 복구합니다.
5. 선택 항목은 `바닥에 스냅`으로 현재 층 바닥에 맞추고, 화살표 버튼으로 한 층씩 올리고 내립니다.
6. `배치를 레이어에 고정`을 켜면 새 배치가 활성 레이어 범위를 벗어나지 않습니다.

레이어는 저작 편의용입니다. 청크 소유권과 Unity 스트리밍은 그대로 2D이며, Export에는 `layer` 인덱스만 기록됩니다.

## 수심 밴드

`수심 밴드` 패널에서 해수면과 표층/중층/심해 두께를 정합니다. 3D 커서와 활성 오브젝트의 수심이 실시간으로 표시되고, 밴드 이름 버튼을 누르면 커서가 그 밴드 바닥으로 갑니다. `수심 밴드 표시`를 켜면 뷰포트에 경계면이 그려집니다. `해수면 값 넘기기`로 버텍스 베이크 설정과 동기화할 수 있습니다.

## 북마크와 청크 이동

`북마크` 패널에서 청크 좌표를 직접 입력해 이동하거나, `현재 시점 저장`으로 이름 붙인 위치를 남깁니다. 북마크는 청크 좌표와 **레이어**를 함께 저장하므로, 이동하면 활성 레이어까지 그때 상태로 복원됩니다.

## 통과 가능성 검사

`통과 검사` 패널은 경사각만 보는 기존 분석으로는 답이 안 나오는 것을 검사합니다.

- `걷기`: 밴드 안에서 **가장 아래 표면**을 찾아 그 위에 섭니다. 경사와 머리 위 공간을 확인해 `경사 과다` / `천장 낮음`을 표시합니다. 동굴 천장 위에 서 있다고 오판하지 않습니다.
- `수영`: 지점 주위 6방향의 여유 공간을 재서 플레이어 반지름보다 좁으면 `좁음`으로 표시합니다.

결과는 뷰포트에 색으로 찍히고, `첫 실패 지점으로 커서 이동`으로 문제 지점을 바로 찾아갑니다. 검사는 **활성 레이어 밴드**를 기준으로 하므로 층을 바꿔가며 확인하세요.

## 아치·바위 군집을 Prefab처럼 등록

1. 아치나 바위 군집을 하나의 Blender Collection으로 묶습니다.
2. `조형물 라이브러리`에서 Registry JSON 경로를 지정합니다.
3. 원본 Collection, Asset ID, 한국어/영어 이름, 분류를 입력합니다.
4. 작은 바위 군집은 `CHUNK`, 큰 아치는 `REGION` 소유권을 권장합니다.
5. DOTS 엔티티로 스폰할 대상이면 `배치 종류`를 `Entity`로 바꾸고 `엔티티 프리팹 ID`, `엔티티 종류`, 플래그를 채웁니다. 프리팹 ID는 Unity 프리팹의 `WorldEntityAuthoring.PrefabId`와 정확히 같아야 합니다.
6. `에셋 등록 / 갱신`을 누릅니다.

원본 Collection은 Blender Asset으로 Mark되고 그 안의 원본 오브젝트는 Export 대상에서 제외됩니다. 배치 결과는 Mesh 복사가 아니라 Collection Instance입니다.

## 엔티티 카탈로그 연결

유니티에서 `WorldBuilder > 월드 > 엔티티 카탈로그` 툴의 `Export Catalog JSON for Blender`를 눌러 JSON을 뽑습니다. 블렌더 `엔티티 카탈로그` 패널에서 그 파일을 지정하면, 프리팹 ID를 손으로 입력하는 대신 이름으로 고를 수 있습니다.

카탈로그에서 고르면 프리팹 ID뿐 아니라 종류·플래그·수명까지 유니티 프리팹 값 그대로 채워집니다. 이후에 값을 바꾸는 건 의도적인 덮어쓰기로 취급합니다. 카탈로그에 없는 ID를 쓰면 Export 검사에서 경고가 뜹니다.

## 엔티티 대량 배치

`분산 배치` 레이어의 에셋 항목은 기본값이 `Auto`입니다. 조형물 라이브러리에 `Entity`로 등록한 에셋이면 스캐터 결과도 자동으로 엔티티가 됩니다. 바이옴·경사·높이 룰이 그대로 적용되므로, 특정 바이옴의 특정 수심대에만 자원 노드를 뿌리는 식으로 쓸 수 있습니다.

항목별로 `Instance`나 `Entity`를 직접 지정해 덮어쓸 수도 있습니다. `Entity`인데 라이브러리에 등록되지 않은 에셋이면 패널에 오류가 표시됩니다.

## 배치

- `커서 위치에 배치`: 3D Cursor 위치에 한 번 배치합니다.
- `표면 배치 도구`: 마우스로 표면을 가리켜 반복 배치합니다.
- 마우스 휠: 5도 회전
- Shift + 휠: 등록된 최소/최대 범위 안에서 크기 조절
- 왼쪽 클릭: 확정 후 계속 배치
- 오른쪽 클릭 또는 Esc: 종료

Export 시 Collection Mesh를 반복 저장하지 않고 `assetId + Transform + layer + streaming_ownership`만 `placements.json`에 기록합니다. Unity `BlenderAssetRegistry`에 같은 Asset ID와 Prefab을 등록해야 합니다.

엔티티 에셋으로 배치한 오브젝트는 이름이 `ENT_`로 시작하고 role이 `ENTITY`가 되며, `entity` 블록이 함께 기록됩니다. Unity 임포트 시 프리팹 ID가 맞지 않거나 `WorldEntityAuthoring`이 없으면 오류로 막힙니다.

## 산호초·바위·해초 Collection Asset 제작

1. `산호초 바위 제작기` 패널을 엽니다.
2. 에셋 종류를 선택합니다.
   - `Complete Reef`: 바위, 모래, 해초, 산호, 자갈이 포함된 완성 세트
   - `Rock Formation`: 바위와 바닥 소품만 포함
   - `Seaweed Patch`: Rule Scatter용 독립 해초 군집
   - `Coral Patch`: Rule Scatter용 독립 산호 군집
3. 바위 세트라면 `Mound`, `Layered Terraces`, `Reef Spire`, `Reef Arch` 중 구조를 선택합니다.
4. Asset ID, 한글/영문 이름, 크기, 불규칙성, 해초·산호 밀도를 설정합니다.
5. `산호초 Collection Asset 생성`을 누릅니다.

결과는 로컬 원점 기준 `WB_ASSET_*` Collection으로 생성되고 Blender Asset으로 표시됩니다. 원본 Collection은 Export 대상에서 제외되며, 현재 3D Cursor에는 확인용 Collection Instance가 배치됩니다. 구조물 라이브러리의 등록 입력칸도 자동으로 채워집니다.

해초 Mesh에는 Unity 셰이더 애니메이션용 `WB_Sway` Vertex Color와 `wb_shader_family = SEAWEED` 메타데이터가 생성됩니다. `12종 변형 시트 생성`을 사용하면 현재 설정을 기준으로 결정론적인 Collection Asset 12개를 한 번에 만듭니다.
